# 元素荒原

像素風的倖存者類遊戲（類似《吸血鬼倖存者》）。你放出的每一招都會改寫地形，地形之間還會繼續連鎖反應。

整個遊戲是單一個 `index.html`，不需要安裝或建置。直接用瀏覽器打開就能玩，也可以用 GitHub Pages 發布。

## 玩法

- 移動：`WASD` 或方向鍵；手機按住畫面任意處拖曳。攻擊會自動施放。
- 暫停：`Esc` 或 `Space`。升級時按 `1` `2` `3` 快速選擇。
- 撐過四個關卡：翠綠草原（5 分）→ 焦土火山（5 分）→ 冰封沼澤（5 分）→ 晶簇深淵（6 分）。等級和法術會帶到下一關。

## 內容

- **5 個職業**：火焰法師、冰霜術士、大地戰士、雷電遊俠、潮汐祭司。
- **4 種難度**：簡單、普通、困難、煉獄。
- **6 個基礎法術**（最高 Lv8）和 **7 個被動**（最高 Lv5）。
- **11 條進化／合成公式**：
  - 進化：法術 Lv8 加上指定被動。
  - 合成：兩個 Lv8 法術合成一個新法術，原本的兩個會消失。
- **20 種地形、50 種地形反應**。例如熔岩加水變黑曜石，灰燼吸水變沃土再開出回血的花，毒沼遇火連鎖爆炸。
- **圖鑑**：合成公式、法術每級效果、已發現的地形反應、地形說明、敵人與關卡。
- **8-bit 配樂**：用 Web Audio 即時合成，主選單和四個關卡各一首，另外有各種音效。

## 平衡測試工具

`tools/` 裡是用來測難度曲線的自動遊玩機器人（需要 Node.js 和 Playwright）：

```sh
cd tools
bash make.sh               # 產生 game.html：在 index.html 加上測試用的掛鉤
node bot.js <職業0-4> <難度0-3> <局數> | python3 summ.py
```

機器人會閃躲敵人、撿經驗寶石，升級時優先選主法術。它會從第一關打到第四關，記錄每 30 秒的等級、血量和敵人數量，倒下時也會列出最後 8 秒是被什麼打死的。
